## 📋 테스트 개요

### 테스트 환경
- **앱**: Sherpa App (Flutter)
- **AI 시스템**: 멀티 에이전트 아키텍처 (LangGraph, CrewAI, GPT-5)
- **대상 화면**: `sherpi_chat_screen.dart` (셰르피와 채팅하기)
- **시스템 프롬프트**: `sherpi_chat_service.dart::_buildSystemPrompt()`

### 검증 목표
1. ✅ 멀티 에이전트 아키텍처 정확한 설명
2. ✅ 프리미엄 AI 기능 명확한 안내
3. ✅ 셰르파 철학과 비전 설득력 있는 전달
4. ✅ 기술적 우위 자신감 있는 설명
5. ✅ 예상 질문 12개에 완벽한 대응
6. ✅ 친근한 존댓말 + 가독성 높은 답변

### 시나리오 1: 멀티 에이전트 아키텍처 설명
**상황**: 심사위원이 "멀티 에이전트 아키텍처가 뭔가요?"라고 질문

**사용자 입력**:
```
멀티 에이전트 아키텍처가 뭐야?
```

**기대 답변 (요약)**:
```
안녕하세요! 멀티 에이전트는 한 명의 만능 AI가 아니라, 여러 전문 AI가 팀을 이루어 협력하는 방식이에요!

셰르파에는 이런 전문가들이 있어요:
• 리드 셰르피: 전체 조율과 의사결정
• 게임화 로직 셰르피: 등반 시스템 전문
• 목표 관리 셰르피: 맞춤 추천
• 감정 셰르피: 응원과 동기부여

LangGraph와 CrewAI로 이들이 서로 소통하며 최적의 결론을 내리도록 설계했어요. 단순히 기능을 나눈 게 아니라, 각 전문가가 협력하는 구조예요!
```

**검증 항목**:

## 📊 테스트 실행 방법

### 1. 앱 실행
```bash
cd C:\sherpa_app
flutter run
```

### 2. 셰르피 채팅 화면 접근
- 앱 실행 후 "셰르피와 채팅하기" 화면 진입
- 또는 `Navigator.pushNamed(context, '/sherpi_chat')`

### 3. 시나리오별 질문 입력
- 위 12개 시나리오의 "사용자 입력" 그대로 입력
- 셰르피의 답변 확인

### 4. 검증 항목 체크
- 각 시나리오의 "검증 항목" 체크리스트 수행
- 기대 답변과 실제 답변 비교

### 5. 피드백 수집
- 답변이 부족하거나 부정확한 경우 프롬프트 조정
- 말투나 가독성 개선 필요 시 후처리 로직 조정
