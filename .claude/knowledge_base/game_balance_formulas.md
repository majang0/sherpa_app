## Part 1: 등반력 시스템

### 1.1 최종 등반력 공식 ✅

```
등반력 = (기본 등반력) × (1 + 능력치 보너스 총합) × (1 + 뱃지 보너스 총합)
```

**코드 위치**: `lib/core/constants/game_constants.dart:40-53`
**상태**: txt 파일과 코드 완벽히 일치 ✅

#### 예시 계산
- 레벨 15, 칭호 보너스 +50
- 체력 15%, 지식 10%, 기술 5%
- 뱃지: '오르막길 정복자(+5%)'와 '지식의 탐구자(+10%)'

```
기본 등반력 = (15 × 10) + 50 = 200
능력치 보너스 = 15% + 10% + 5% = 30%
뱃지 보너스 = 5% + 10% = 15%

최종 등반력 = 200 × (1 + 0.30) × (1 + 0.15) = 200 × 1.30 × 1.15 = 299
```

### 1.2 기본 등반력 계산 ✅

```
기본 등반력 = (레벨 × 10) + 칭호 보너스
```

**코드 위치**: `lib/core/constants/game_constants.dart:12-14`

### 1.3 능력치 보너스 (⚠️ 중요!)

## Part 5: 등반 보상 시스템

### 5.1 성공 시 보상 공식 (복잡!) ✅

#### 경험치 (XP) 공식
```
지능형 기본 XP = 시간당 32.5 × 지수감쇠곡선 × 중급가속보너스 × 초반페널티 × 보정값

최종 XP = 지능형 기본 XP × (0.9 ~ 1.1 랜덤)
```

**공식 구성 요소**:
- **지수감쇠곡선**: `1.0 - e^(-0.12 × 난이도)`
- **중급가속보너스**: 난이도 ≥15일 때 `1.0 + ((난이도 - 15) × 0.015)`
- **초반페널티**: 난이도 <20일 때 `0.8 + (난이도 × 0.01)`
- **보정값**: `(난이도 / 80.0 + 0.4)`

**코드 위치**: `lib/core/constants/game_constants.dart:176-201`
**상태**: txt 파일과 코드 완벽히 일치 ✅

#### 포인트 (Points) 공식
```
지능형 기본 Point = 시간당 30.0 × 지수감쇠곡선 × 중급가속보너스 × 초반페널티 × 보정값

최종 Point = 지능형 기본 Point × (0.8 ~ 1.2 랜덤)
```

**공식 구성 요소**:
- **지수감쇠곡선**: `1.0 - e^(-0.09 × 난이도)` (XP와 k 값 다름!)
- **중급가속보너스**: 난이도 ≥15일 때 `1.0 + ((난이도 - 15) × 0.012)`
- **초반페널티**: 난이도 <20일 때 `0.85 + (난이도 × 0.0075)`
- **보정값**: `(난이도 / 80.0 + 0.3)`

### 5.3 성공 확률 공식 ✅

```
최종 성공 확률 = 기본 성공 확률(등반력 비율) + 의지 보정치 + 뱃지 보너스
```

#### 기본 성공 확률 (power_ratio = userPower / mountainPower)

```python
def climbing_success_probability(power_ratio):
    if power_ratio < 1:
        # 등반력 부족 시: 급격한 확률 감소 (3제곱 함수)
        prob = 0.05 + 0.45 * (power_ratio ** 3)
    else:
        # 등반력 초과 시: 완만한 확률 증가 (지수 함수의 역함수)
        prob = 0.5 + 0.45 * (1 - exp(-0.5 * (power_ratio - 1)))
        prob = min(prob, 0.95)  # 최대 95%로 제한
    return prob
```

#### 의지 보정치
```
의지 보정치 = (의지 능력치 %) × 0.1
```

#### 뱃지 보너스
```
모든 장착 뱃지의 성공 확률 보너스 합계
```
