# 📅 셰르파 플래너 개선 전략서
*2025년 1월 - 한국 플래너 앱 시장 분석 및 개선 방향*

## 📊 1. 시장 조사 결과 (2024-2025 한국 플래너 앱)

### 1.1 주요 경쟁 앱 분석

#### 🔹 하루하루 (HaruHaru)
- **특징**: 2019-2020 앱스토어 추천 앱
- **핵심 기능**:
  - 일일 스케줄 한눈에 보기
  - 위젯을 통한 빠른 일정 확인
  - 알람 알림으로 일정 관리
- **성공 요인**: 단순한 인터페이스, 빠른 접근성

#### 🔹 투두메이트 (TodoMate) 
- **특징**: 50만+ 다운로드, 평점 4.7
- **핵심 기능**:
  - 목표 기반 태스크 정리
  - 친구 팔로우 및 일상 공유
  - 이모티콘/스티커 반응
  - PC 연동 지원
- **성공 요인**: 소셜 기능, 목표 중심 설계

#### 🔹 챌린저스 (Challengers)
- **특징**: 120만 사용자, 20-34세 50% 이상
- **핵심 기능**:
  - 습관 형성에 돈 걸기 (85% 달성시 전액 환급)
  - 자동 만보계 및 포인트 적립
  - '갓생몬' 캐릭터 진화 시스템
- **성공 요인**: 금전적 동기부여, 캐릭터 성장 시각화

### 1.2 핵심 인사이트
1. **단순성**: 복잡한 기능보다 직관적인 UI 선호
2. **시각화**: 진행 상황을 한눈에 볼 수 있는 디자인
3. **게이미피케이션**: 보상과 캐릭터 성장 요소
4. **소셜 요소**: 친구와 함께하는 동기부여
5. **빠른 접근**: 위젯 지원 필수

## 🎯 2. 현재 셰르파 플래너의 문제점

### 2.1 복잡성 이슈
- ❌ 3개 탭 구조로 인한 복잡한 네비게이션
- ❌ AI 제안이 메인 UI를 가림
- ❌ 목표 입력 프로세스가 너무 길음
- ❌ 저장된 목표 관리가 직관적이지 않음

### 2.2 셰르파 앱과의 부조화
- ❌ 산 등반 메타포와 연결성 부족
- ❌ 기존 포인트/퀘스트 시스템과 분리됨
- ❌ 셰르피 캐릭터 활용 미흡
- ❌ 일일 활동 기록과 연동 부족

## 🏔️ 3. 개선 방향: "등산로 플래너"

### 3.1 핵심 컨셉
**"목표를 산 정상으로, 계획을 등산로로 시각화"**

- 각 목표 = 정복할 산봉우리
- 일일 계획 = 등산로의 체크포인트
- 진행 상황 = 현재 고도
- 완료 = 정상 도달 및 깃발 꽂기

### 3.2 디자인 원칙
1. **One-Screen Design**: 모든 핵심 기능을 한 화면에
2. **Visual First**: 텍스트보다 비주얼 중심
3. **Minimal Input**: 최소한의 입력으로 최대 효과
4. **Smart Defaults**: AI가 배경에서 조용히 도움

## 📱 4. 새로운 플래너 UI/UX 설계

### 4.1 메인 화면 구성

```
┌─────────────────────────────────┐
│     🏔️ 이번 달 등반 계획        │
│                                 │
│  [산 경로 비주얼라이제이션]      │
│   ⛰️──🚩──🚩──🏔️               │
│   현재▲  목표1  목표2  최종목표  │
│                                 │
├─────────────────────────────────┤
│  📅 오늘의 체크포인트            │
│  □ 운동 30분 (🏔️ 건강봉)       │
│  ✓ 독서 1장 (🏔️ 지식봉)        │
│  □ 일기 작성 (🏔️ 성찰봉)       │
├─────────────────────────────────┤
│  [+ 새 목표 추가] 버튼           │
└─────────────────────────────────┘
```

### 4.2 목표 입력 플로우 (원스텝)

```
사용자: [+ 새 목표] 탭
↓
팝업: "어떤 산을 정복하시겠어요?"
      [목표 입력창]
      
      💡 AI 힌트 (작게 표시)
      "최근 운동을 자주 하셨네요!
       '주 3회 등산' 어떠세요?"
↓
입력 완료 → 즉시 산 경로에 표시
```

### 4.3 일일 뷰 / 월간 뷰 전환

```
[일일 뷰]
오늘의 등반 일정을 체크포인트로 표시
각 활동 = 작은 깃발 🚩

[주간 뷰] 
7일간 등반 경로를 한눈에
진행률을 고도로 표시

[월간 뷰]
전체 산맥 조망
정복한 봉우리에 깃발 표시
```

## 🔧 5. 기능 상세 명세

### 5.1 핵심 기능

#### A. 스마트 목표 입력
```dart
- 한 줄 입력으로 목표 생성
- 자동 카테고리 분류 (AI)
- 기간 자동 추천
- 관련 일일 활동 자동 연결
```

#### B. 비주얼 프로그레스
```dart
- 산 등반 애니메이션
- 실시간 고도 표시
- 날씨 효과 (달성률에 따라)
- 정상 도달시 축하 애니메이션
```

#### C. AI 도우미 (셰르피)
```dart
- 조용한 힌트 제공
- 진행 막힐 때만 나타남
- 격려 메시지
- 스마트 일정 조정 제안
```

#### D. 기존 시스템 연동
```dart
- 일일 활동 → 자동 체크포인트
- 퀘스트 완료 → 고도 상승
- 포인트 획득 → 등반 장비 업그레이드
- 레벨업 → 새로운 산 해금
```

### 5.2 위젯 지원
```dart
- 홈 화면 위젯: 오늘의 등반 진행률
- 잠금 화면 위젯: 다음 체크포인트
- 알림: 체크포인트 도달 알림
```

## 📌 결론

셰르파 플래너를 **"복잡한 계획 도구"**에서 **"즐거운 목표 달성 게임"**으로 전환하여, 사용자가 매일 자연스럽게 목표를 확인하고 달성하도록 유도합니다.

핵심은 **단순함**, **시각적 즐거움**, 그리고 **자연스러운 동기부여**입니다.

이 전략을 통해 셰르파는 단순한 플래너 앱을 넘어, 사용자의 성장 여정을 함께하는 **"디지털 셰르파"**가 될 것입니다.
