## 🔄 사용자 플로우

### Flow 1: 첫 사용자 온보딩

```
시작
  │
  ▼
[환영 화면]
"함께 목표를 달성해요!"
  │
  ▼
[간단 설문]
"어떤 목표가 있으신가요?"
□ 건강 □ 학습 □ 습관
  │
  ▼
[첫 목표 설정]
"첫 번째 산을 선택하세요"
  │
  ▼
[메인 화면]
산 경로 표시
```

### Flow 2: 일일 루틴

```
앱 실행
  │
  ▼
[메인 화면]
오늘의 체크포인트 확인
  │
  ├─> 체크포인트 완료
  │     │
  │     ▼
  │   즉시 피드백
  │   (+포인트, 애니메이션)
  │
  └─> 새 목표 추가
        │
        ▼
      빠른 입력
        │
        ▼
      목표 생성
        │
        ▼
      산 추가됨
```

### Flow 3: 목표 완료 플로우

```
마지막 체크포인트 완료
         │
         ▼
    진행률 100%
         │
         ▼
   [축하 애니메이션]
   깃발 꽂기 + 폭죽
         │
         ▼
    보상 획득
         │
         ▼
   셰르피 축하 메시지
         │
         ▼
   다음 목표 추천
```

## 📊 Before & After 비교

### Before (현재 복잡한 버전)
```
문제점:
- 3개 탭 네비게이션
- 복잡한 입력 폼
- AI 제안이 화면 절반 차지
- 목표 리스트가 ExpansionTile
- 시각적 진행률 없음
- 동기부여 요소 부족

사용 시간: 평균 3-5분
완료율: 약 40%
```

### After (개선된 버전)
```
개선점:
- 단일 화면 구성
- 30초 내 목표 생성
- 시각적 산 경로
- 즉각적인 피드백
- 게임같은 진행률
- 보상 시스템 통합

예상 사용 시간: 30초-1분
예상 완료율: 70% 이상
```

## 🎮 인터랙션 디테일

### 1. 체크포인트 체크 애니메이션
```
탭 → 체크박스 회전 → ✓ 표시 → 
포인트 +50 플로팅 → 진행바 증가 →
산 경로 업데이트 → 캐릭터 이동
```

### 2. 목표 생성 애니메이션
```
FAB 탭 → Bottom Sheet 슬라이드업 →
키보드 자동 포커스 → 입력 →
생성 버튼 → Sheet 닫힘 →
산이 솟아오름 → 경로 재계산
```

### 3. 정상 도달 시퀀스
```
100% 도달 → 화면 페이드 →
축하 화면 → 깃발 애니메이션 →
폭죽 파티클 → 보상 표시 →
셰르피 등장 → 다음 추천
```
