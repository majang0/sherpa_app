# 셰르피 AI 시스템 개선 로드맵 (2025)

## 🎯 개요

현재 셰르파 앱에 구현된 AI 시스템은 기획 문서에서 제안한 것보다 훨씬 고도화되어 있습니다. 그러나 복잡성, 사용자 경험, 투명성 면에서 개선이 필요한 상황입니다. 이 로드맵은 향후 3개월간 체계적인 개선을 통해 더 나은 사용자 경험을 제공하기 위한 계획을 제시합니다.

## 📊 현재 상태 분석

### ✅ 잘 구현된 부분
- **하이브리드 시스템**: 90% 정적 + 10% AI로 성능과 품질의 균형
- **고도화된 AI 엔진**: Gemini 2.5-flash 기반 개인화 시스템
- **4단계 AI 사용 레벨**: 명확한 기준으로 적절한 AI 활용
- **캐싱 시스템**: 7일 캐시로 즉시 응답 보장
- **성격 유형별 개인화**: 성취형, 탐험형, 지식형, 사교형 맞춤 응답

### ⚠️ 개선이 필요한 부분
- **과도한 복잡성**: 유지보수와 이해가 어려운 아키텍처
- **불완전한 개인화**: 일부 개인화 기능이 비활성화된 상태
- **투명성 부족**: 사용자가 AI 사용 여부를 알기 어려움
- **제한된 상호작용**: 전용 채팅 인터페이스 부재
- **피드백 루프 부족**: 사용자 만족도 기반 개선 시스템 없음

## 🗓️ 3개월 개선 계획

### 📅 Phase 1: 단순화와 최적화 (1개월)
**목표**: 현재 시스템의 복잡성을 줄이고 성능을 최적화

#### Week 1-2: 아키텍처 단순화
- [ ] **4단계 → 3단계 AI 레벨 재구성**
  - `always`, `smart`, `minimal`로 단순화
  - 사용 기준 명확화 및 문서 업데이트
- [ ] **개인화 시스템 정리**
  - 비활성화된 개인화 코드 완전 제거
  - 핵심 개인화 기능만 유지
- [ ] **코드 중복 제거**
  - 유사한 기능들 통합
  - 불필요한 추상화 레이어 제거

#### Week 3-4: 성능 최적화
- [ ] **API 호출 최적화**
  - 불필요한 백그라운드 생성 줄이기
  - API 호출 패턴 분석 및 개선
- [ ] **캐시 전략 재검토**
  - 7일 → 3일로 만료 기간 단축 검토
  - 선택적 사전 생성으로 변경
- [ ] **메모리 사용량 최적화**
  - 캐시 크기 제한
  - 가비지 컬렉션 최적화

**성공 지표**:
- 코드 복잡도 30% 감소
- API 호출 횟수 20% 감소
- 앱 메모리 사용량 15% 감소

---

### 📅 Phase 2: 사용자 경험 개선 (1개월)
**목표**: AI 사용의 투명성을 높이고 사용자 제어권 강화

#### Week 1-2: UI/UX 투명성 강화
- [ ] **메시지 소스 표시**
  - ⚡ 즉시 (정적), 🚀 캐시 (AI), 🤖 실시간 (AI) 아이콘 추가
  - 응답 시간 표시
- [ ] **AI 설정 페이지 구현**
  - AI 사용 빈도 조절 슬라이더
  - AI vs 정적 메시지 비율 설정
  - 개인화 수준 선택 옵션

#### Week 3-4: 사용자 피드백 시스템
- [ ] **메시지 평가 기능**
  - 👍👎 피드백 버튼 추가
  - 평가 결과 수집 및 분석
- [ ] **선호도 학습 시스템**
  - 사용자 피드백 기반 응답 개선
  - 개인별 메시지 톤 조정
- [ ] **사용 통계 대시보드**
  - 사용자별 AI 상호작용 통계
  - 만족도 트렌드 표시

**성공 지표**:
- 사용자 만족도 15% 향상
- AI 설정 사용률 40% 달성
- 피드백 참여율 25% 달성

---

### 📅 Phase 3: 고급 기능 구현 (1개월)
**목표**: 전용 채팅 인터페이스와 데이터 기반 최적화

#### Week 1-2: 전용 채팅 인터페이스
- [ ] **SherpiChatScreen 구현**
  - 전용 채팅 화면 UI/UX 설계
  - 실시간 대화 기능 구현
  - 메시지 히스토리 저장 및 관리
- [ ] **대화 컨텍스트 유지**
  - 장기 대화 기억 시스템
  - 이전 대화 참조 기능
  - 대화 주제별 분류

#### Week 3-4: 데이터 기반 최적화
- [ ] **A/B 테스트 인프라**
  - AI 사용 비율 테스트 (5% vs 10% vs 15%)
  - 메시지 길이 최적화 테스트
  - 개인화 수준 테스트
- [ ] **상호작용 메트릭 수집**
  - 사용자 행동 패턴 분석
  - 대화 만족도 측정
  - 성능 메트릭 대시보드

**성공 지표**:
- 채팅 화면 이용률 30% 달성
- 평균 대화 길이 5턴 달성
- A/B 테스트 기반 최적 설정 도출
