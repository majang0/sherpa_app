## 1. 시스템 개요

셰르피 AI 프롬프트 시스템은 **Gemini 2.5 Flash** 모델을 기반으로 한 지능형 대화 생성 시스템입니다. 사용자의 활동, 성격, 친밀도에 따라 개인화된 응답을 생성하며, 캐싱과 폴백 메커니즘을 통해 안정적인 서비스를 제공합니다.

### 핵심 특징
- **3단계 AI 레벨 시스템**: Premium (100%), Smart (80%), Basic (40%)
- **6가지 활동별 특화 프롬프트**: 운동, 공부, 일기, 퀘스트, 등산, 모임
- **5가지 성격 유형별 개인화**: 활발형, 차분형, 유머형, 진지형, 균형형
- **실시간 응답 보장**: 캐시 → AI → 정적 메시지 폴백 체계
- **친밀도 기반 AI 사용률 조정**: 레벨 1-10에 따른 동적 조정

## 2. API 설정 및 토큰 관리

### API 키 관리 체계

API 키는 **3단계 우선순위 시스템**으로 안전하게 관리됩니다:

#### 1순위: 환경 파일 (.env)
- 프로젝트 루트의 `.env` 파일에서 API 키 로드
- 형식: `GEMINI_API_KEY=AIzaSy...`
- 보안: `.gitignore`에 포함되어 버전 관리에서 제외
- 유효성 검증: AIza로 시작하는 올바른 형식 확인

#### 2순위: 컴파일타임 환경변수
- Flutter 실행 시 전달: `flutter run --dart-define=GEMINI_API_KEY=...`
- 빌드 시점에 API 키 주입
- CI/CD 파이프라인에서 활용 가능

#### 3순위: 플레이스홀더
- 개발 환경용 기본값: `YOUR_GEMINI_API_KEY_HERE`
- 실제 서비스에서는 작동하지 않음
- API 키가 설정되지 않은 경우 자동으로 정적 메시지로 폴백

### Gemini 모델 설정

**고정 모델**: `gemini-2.5-flash`
- 빠른 응답 속도와 효율성을 위해 Flash 모델 사용
- 모델 변경 금지 (하드코딩됨)
- Generation Config:
  - Temperature: 0.8 (창의성과 일관성의 균형)
  - Max Output Tokens: 1000 (충분한 응답 길이)
  - TopK: 40, TopP: 0.95 (다양성 제어)

### 안전 설정
모든 HarmCategory에 대해 `HarmBlockThreshold.none` 설정
- 과도한 필터링으로 인한 응답 차단 방지
- 대신 응답 후처리에서 부적절한 표현 필터링

## 3. 프롬프트 시스템 아키텍처

### 2단계 프롬프트 구조

#### 레벨 1: 활동별 특화 프롬프트
- 6가지 활동 유형에 대한 전문 프롬프트 템플릿
- 각 활동의 구체적 데이터와 컨텍스트 포함
- 사용자 통계와 성과 분석 기반

#### 레벨 2: 기본 범용 프롬프트
- 활동 데이터가 없는 일반 상황용
- 간단한 인사, 격려, 안내 메시지
- 성격과 친밀도만 반영

### 프롬프트 구성 요소

모든 프롬프트는 **4개 섹션**으로 구성:

1. **역할 정의 및 컨텍스트**
   - "당신은 '셰르피'입니다"로 시작
   - 사용자와의 관계 정의
   - 현재 상황 설명

2. **세션/활동 정보**
   - 현재 활동의 구체적 데이터
   - 수치, 시간, 강도 등 정량적 정보
   - 특별한 성취나 기록

3. **사용자 통계 및 패턴**
   - 누적 활동 기록
   - 주간/월간 통계
   - 선호도와 경향성

4. **응답 가이드라인**
   - 성격별 톤과 스타일 지침
   - 강조해야 할 포인트
   - 길이 제한 (50자 이내)

## 4. 활동별 특화 프롬프트 상세

### 4.1 운동 프롬프트 (Exercise)

#### 포함되는 데이터
- **세션 정보**: 운동 종류, 시간(분), 강도, 칼로리, 심박수
- **통계**: 오늘 총 운동 시간, 주간 운동량, 월간 패턴
- **성과**: 개인 최고 기록, 연속 운동 일수, 트렌드(상승/안정/하락)
- **동기부여 포인트**: 특별한 성취, 목표 달성률, 개선 사항

#### 프롬프트 특징
- 구체적 수치 언급으로 성취감 극대화
- 개인 기록 달성 시 특별 축하 메시지
- 운동 습관 형성 격려
- 다음 세션에 대한 기대감 조성

#### 응답 예시 상황
- 개인 최고 기록 달성 → "와! 35분 신기록 달성! 대단해요!"
- 3일 연속 운동 → "3일 연속 운동 중! 습관이 만들어지고 있어요!"
- 강도 높은 운동 완료 → "고강도 운동 완료! 진짜 대단해요!"

### 4.2 공부/독서 프롬프트 (Study)

#### 포함되는 데이터
- **세션 정보**: 책 제목, 읽은 페이지, 평점(1-5), 독서 시간
- **독서 습관**: 주간 독서량, 월간 완독 도서, 선호 장르
- **통계**: 총 독서 시간, 독서 레벨, 평균 평점
- **인사이트**: 다양성 지수, 완독률, 지적 성장 지표

#### 프롬프트 특징
- 지적 호기심 자극
- 책에 대한 관심 표현
- 독서를 통한 성장 강조
- 다음 책에 대한 추천이나 기대

#### 응답 예시 상황
- 100페이지 이상 독서 → "오늘 정말 많이 읽으셨네요! 몰입감이 대단해요!"
- 높은 평점 부여 → "5점이라니! 정말 좋은 책이었나봐요!"
- 다양한 장르 독서 → "다양한 장르를 섭렵하시는 모습이 멋져요!"

### 4.3 일기 프롬프트 (Diary)

#### 포함되는 데이터
- **감정 정보**: 오늘의 기분, 감정 키워드, 감정 강도
- **패턴 분석**: 주간 감정 트렌드, 긍정성 지수, 주된 감정
- **성장 지표**: 감정 인식 수준, 표현력, 성찰 깊이
- **습관**: 연속 작성 일수, 작성 시간대, 선호 주제

#### 프롬프트 특징
- 공감적이고 따뜻한 반응
- 감정 인정과 수용
- 성찰의 가치 강조
- 내일도 마음을 나누고 싶게 만드는 메시지

#### 감정별 응답 가이드
- 행복한 감정 → 함께 축하하고 긍정 에너지 증폭
- 슬픈 감정 → 따뜻한 위로와 공감
- 화난 감정 → 감정 이해와 차분한 격려
- 중립적 감정 → 함께 있다는 느낌 전달

### 4.4 퀘스트 프롬프트 (Quest)

#### 포함되는 데이터
- **퀘스트 정보**: 이름, 난이도, 보상 포인트, 카테고리
- **진행 상황**: 오늘 완료 수, 전체 완료율, 주간 완료
- **보상**: 획득 포인트, 랭크, 특별 보상
- **마스터리**: 선호 퀘스트 유형, 전문 분야, 도전 과제

#### 프롬프트 특징
- RPG 게임 가이드 느낌
- 성취감과 보상 강조
- 모험적이고 흥미진진한 톤
- 다음 퀘스트에 대한 도전 의욕 자극

#### 난이도별 응답
- Easy → 꾸준한 수행 격려
- Normal → 균형잡힌 칭찬
- Hard → 특별한 성취 인정
- Extreme → 최고 수준의 찬사

### 4.5 등반 프롬프트 (Climbing)

#### 포함되는 데이터
- **등반 정보**: 산 이름, 고도, 진행도(%), 성공 여부
- **기록**: 정복한 산 개수, 성공률, 최고 난이도
- **도전**: 현재 도전 중인 산, 다음 목표, 남은 과제
- **인사이트**: 체력 향상도, 기술 발전, 인내력

#### 프롬프트 특징
- 산악 가이드의 든든한 톤
- 등반을 인생의 도전과 연결
- 정상 등정 시 특별한 축하
- 실패 시 도전 정신 격려

#### 성공/실패별 응답
- 성공 → "정상 등정 축하! 정상의 풍경이 최고죠!"
- 80% 이상 진행 → "거의 다 왔어요! 조금만 더!"
- 실패 → "오늘의 도전이 내일의 성공을 만들어요!"

### 4.6 모임 프롬프트 (Meeting)

#### 포함되는 데이터
- **모임 정보**: 제목, 유형, 참가자 수, 장소
- **소셜 활동**: 오늘/주간 모임 수, 총 참여 횟수
- **네트워킹**: 총 연결 수, 다양성 지수, 일관성
- **성과**: 소셜 점수, 선호 모임 유형, 영향력

#### 프롬프트 특징
- 사교적이고 따뜻한 톤
- 사회적 연결의 가치 강조
- 새로운 만남 격려
- 커뮤니티 기여 인정

#### 모임 규모별 응답
- 소규모(~5명) → 친밀함의 가치 강조
- 중규모(6-15명) → 균형잡힌 소통 칭찬
- 대규모(16명+) → 큰 모임 참여 용기 인정

## 5. 상황별 AI 사용 결정 로직

### AI 사용 레벨 정의

#### Premium (100% AI)
**항상 AI 사용하는 중요한 순간**
- 활동 완료: 운동, 공부, 일기 (무조건 AI)
- 특별한 순간: 환영 인사, 오랜만의 접속, 레벨업
- 마일스톤: 특별 이벤트, 중요 성취

#### Smart (80% AI)
**높은 확률로 AI 사용하는 성취 순간**
- 뱃지 획득, 등산 성공, 퀘스트 완료
- 업적 달성, 모임 참여, 스탯 상승
- 친밀도와 성격에 따라 60-95% 사용

#### Basic (40% AI)
**일상적 상호작용**
- 일반 대화, 안내, 인사, 격려
- 친밀도에 따라 15-55% 사용
- 대부분 정적 메시지 사용

### 친밀도 시스템 (1-10 레벨)

**AI 사용률 계산 공식**
- 기본 비율: 50% + (친밀도-1) × 3.3%
- 레벨 1: 50% AI 사용
- レベル 5: 63% AI 사용
- 레벨 10: 80% AI 사용

**친밀도별 특징**
- 낮은 친밀도(1-3): 정적 메시지 위주, AI는 특별한 순간만
- 중간 친밀도(4-7): 균형잡힌 AI 사용, 점진적 개인화
- 높은 친밀도(8-10): 높은 AI 사용률, 깊은 개인화

### 성격별 AI 사용률 조정

#### 활발형 (+8%)
- 더 많은 AI 사용으로 역동적 응답
- 감정 표현이 풍부한 메시지 선호

#### 유머형 (+5%)
- AI의 창의적 응답 활용
- 재치있는 표현 생성

#### 차분형 (+2%)
- 신중한 AI 사용
- 안정적이고 일관된 메시지

#### 진지형 (-2%)
- 정확한 정보 우선
- 과도한 감정 표현 자제

#### 균형형 (±0%)
- 기본 AI 사용률 유지
- 상황에 따른 유연한 조정

## 6. 프롬프트 생성 및 전달 흐름

### 전체 처리 흐름

#### Step 1: 컨텍스트 수신
1. SherpiContext (31가지 상황 중 하나)
2. userContext (사용자 활동 데이터)
3. gameContext (게임 상태, 성격, 친밀도)

#### Step 2: AI 사용 결정
1. 컨텍스트별 AI 레벨 확인 (Premium/Smart/Basic)
2. 친밀도 기반 사용률 계산
3. 성격별 조정 적용
4. 확률적 결정 (난수 기반)

#### Step 3: 프롬프트 생성
**활동 데이터 있는 경우:**
1. ActivityPromptTemplates에서 해당 활동 템플릿 선택
2. 활동 데이터 주입 (세션 정보, 통계, 성과)
3. 성격별 가이드라인 추가
4. 응답 제한 설정 (50자, 한국어)

**활동 데이터 없는 경우:**
1. 기본 프롬프트 템플릿 사용
2. 사용자 이름, 성격, 상황만 포함
3. 간단한 지침 (2-3문장, 이모지 1-2개)

#### Step 4: AI 호출
1. Gemini Chat 세션 시작
2. 프롬프트 전송
3. 응답 수신 (2-4초)
4. 에러 시 폴백 처리

#### Step 5: 응답 후처리
1. 길이 제한 (150자)
2. 부적절한 표현 필터링
3. 이모지 개수 조정
4. 최종 포맷팅

### 메시지 소스 우선순위

#### 1순위: AI 캐시 (0ms)
- 사전 생성된 AI 메시지
- 즉시 응답 가능
- 24시간 유효

#### 2순위: 실시간 AI (2-4초)
- Gemini API 실시간 호출
- 개인화된 응답 생성
- 최신 컨텍스트 반영

#### 3순위: 정적 메시지 (0ms)
- 사전 정의된 메시지 풀
- 성격별 변형 제공
- 폴백 안전장치

## 7. AI 메시지 캐싱 시스템

### 캐시 구조

#### CachedMessage 객체
- **message**: 생성된 AI 메시지 텍스트
- **generatedAt**: 생성 시각
- **userContext**: 생성 시 사용자 컨텍스트
- **lastAccessTime**: LRU용 마지막 접근 시간

#### 캐시 키 생성
- 형식: `{context_name}_{user_hash}`
- User Hash: 레벨과 연속 접속일 기반
- 개인화된 캐시 분리

### 캐시 정책

#### 만료 정책
- **유효 기간**: 24시간
- **자동 정리**: 만료된 캐시 자동 삭제
- **LRU**: 최대 50개 캐시 유지

#### 백그라운드 생성 (현재 비활성화)
- 원래 3개 핵심 컨텍스트 사전 생성
- FormatException 문제로 비활성화
- 향후 SDK 업데이트 후 재활성화 예정

### 캐시 성능 영향
- **캐시 히트**: 즉시 응답 (0ms)
- **캐시 미스**: AI 생성 필요 (2-4초)
- **메모리 사용**: 최대 50개 메시지 (약 100KB)

## 8. 성격별 개인화 시스템

### 5가지 성격 유형

#### 활발형 (Energetic)
- **특징**: 에너지 넘치고 열정적
- **말투**: 느낌표 많음, 이모지 2-3개
- **AI 사용률**: +8% 보너스
- **예시**: "와! 정말 대단해요!! 🎉✨"

#### 차분형 (Calm)
- **특징**: 조용하고 사려 깊음
- **말투**: 차분한 어조, 이모지 1개
- **AI 사용률**: +2% 보너스
- **예시**: "오늘도 차근차근 잘 해내셨네요 🌱"

#### 유머형 (Humorous)
- **특징**: 재치있고 웃음 유발
- **말투**: 농담 섞인 표현
- **AI 사용률**: +5% 보너스
- **예시**: "오늘도 퀘스트 사냥 성공! 몬스터들이 벌벌 떨어요 😄"

#### 진지형 (Serious)
- **특징**: 성실하고 꼼꼼함
- **말투**: 정확한 정보 전달
- **AI 사용률**: -2% 보너스
- **예시**: "목표의 87%를 달성하셨습니다. 우수한 성과입니다."

#### 균형형 (Balanced)
- **특징**: 상황에 따라 유연함
- **말투**: 적절히 조화로운 표현
- **AI 사용률**: ±0% (기본값)
- **예시**: "잘 하셨어요! 꾸준히 성장하고 있네요 😊"

### 개인화 설정 요소

#### PersonalizationSettings
- **personalityType**: 5가지 성격 중 선택
- **nickname**: 셰르피 호칭 커스텀
- **userPreferredName**: 사용자 호칭
- **messageFrequencyMultiplier**: 메시지 빈도 조절 (0.3-1.5)
- **useEmojisInMessages**: 이모지 사용 여부
- **enablePersonalizedTone**: 개인화 톤 활성화

### 메시지 빈도 조절

#### 빈도 배율 영향
- **최소 (0.3)**: AI 사용률 70% 감소
- **보통 (1.0)**: 기본 AI 사용률
- **최대 (1.5)**: AI 사용률 50% 증가

#### 적용 예시
- 조용한 사용자: 0.3 배율로 메시지 감소
- 활발한 사용자: 1.5 배율로 상호작용 증가

- **감지**: try-catch 블록
