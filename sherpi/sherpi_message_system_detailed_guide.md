## 🎯 시스템 개요

셰르피 메시지 시스템은 사용자의 활동과 상황에 따라 적절한 메시지를 선택하고 표시하는 지능형 시스템입니다.

### 핵심 특징
- **31개의 상황별 컨텍스트**로 세분화된 메시지
- **각 컨텍스트당 4-5개의 정적 메시지** 풀
- **3단계 AI 레벨** (Premium 100%, Smart 80%, Basic 40%)
- **5가지 성격 타입**별 메시지 톤 조정
- **13가지 감정 상태**와 연동된 시각적 표현
- **친밀도 레벨(1-10)**에 따른 AI 사용률 조정

## 🔄 메시지 호출 플로우 상세 분석

### 전체 플로우 다이어그램

```
사용자 활동 발생
    ↓
[1] GlobalUserProvider.handleActivityCompletion()
    ├── 활동 데이터 저장
    ├── 경험치/포인트 지급
    ├── 능력치 증가 처리
    └── _triggerSherpiReaction() 호출
            ↓
[2] _triggerSherpiReaction()
    ├── 활동 타입 분석
    ├── SherpiContext 결정
    ├── 감정(Emotion) 선택
    └── SherpiProvider.showMessage() 호출
            ↓
[3] SherpiProvider.showMessage()
    ├── 중복 메시지 검사 (3초 룰)
    ├── 감정 분석 (활동 완료 시)
    └── SmartSherpiManager.getMessage() 호출
            ↓
[4] SmartSherpiManager.getMessage()
    ├── AI 사용 레벨 결정 (Premium/Smart/Basic)
    ├── 친밀도 레벨 확인 (1-10)
    ├── 성격 타입 확인 (5가지)
    └── 메시지 소스 선택
            ↓
[5] 메시지 소스 선택
    ├── Option 1: AI Cached (즉시, 캐시된 AI)
    ├── Option 2: AI Realtime (2-4초, 실시간 AI)
    └── Option 3: Static (즉시, 정적 메시지)
            ↓
[6] SherpiMessageCard 표시
    ├── 감정별 색상 그라데이션 적용
    ├── 슬라이드업 애니메이션
    ├── 메시지 소스 표시 (⚡/🚀/🤖)
    └── 4초 후 자동 숨김
```

### 상세 단계별 설명

#### 1단계: 활동 완료 처리 (`handleActivityCompletion`)

**위치**: `lib/shared/providers/global_user_provider.dart`

```dart
void handleActivityCompletion({
  required String activityType,    // 'exercise', 'reading', 'diary', 'quest_easy' 등
  required double xp,              // 획득 경험치
  required int points,             // 획득 포인트
  required Map<String, double> statIncreases,  // 능력치 증가
  required String message,         // 시스템 메시지
  Map<String, dynamic>? additionalData,  // 추가 데이터
})
```

**처리 과정**:
1. 경험치 지급 → 레벨업 체크
2. 포인트 지급 (PointSource 매핑)
3. 능력치 증가 적용
4. `_triggerSherpiReaction()` 호출 (climbing 제외)
5. 퀘스트 시스템 알림

#### 2단계: 셰르피 반응 트리거 (`_triggerSherpiReaction`)

**활동별 컨텍스트 매핑**:

| 활동 타입 | SherpiContext | 감정 | 비고 |
|----------|---------------|------|------|
| reading | studyComplete | thinking | 항상 AI (Premium) |
| exercise | exerciseComplete | happy | 항상 AI (Premium) |
| diary | diaryWritten | defaults | 항상 AI (Premium) |
| quest_* | questComplete | cheering | 단순 퀘스트 제외 |
| meeting_host | meetingJoined | happy | 호스팅 보너스 |
| meeting_participant | meetingJoined | happy | 참가 보너스 |
| all_goals_reward | achievement | special | 특별 메시지 |

**특수 로직**:
- **탭 방문 퀘스트 필터링**: "확인", "둘러보기", "현황" 등 단순 퀘스트는 메시지 없음
- **전체 목표 달성**: 커스텀 메시지로 즉시 표시 (AI 미사용)
- **높은 경험치 획득**: 100XP 이상 시 특별 반응

#### 3단계: 메시지 표시 (`showMessage`)

**위치**: `lib/shared/providers/global_sherpi_provider.dart`

**중복 방지 메커니즘**:
- **전역 락**: `_isShowingMessage` 플래그로 동시 호출 방지
- **3초 룰**: 같은 컨텍스트 3초 내 중복 무시
- **메시지 비교**: 같은 내용 5초 내 중복 무시

**감정 분석 (활동 완료 시)**:
```dart
if (_isActivityCompletionContext(context) && userContext != null) {
  selectedEmotion = _analyzeEmotionFromActivity(userContext);
}
```

**활동별 감정 분석 예시**:
- 운동: 강도 높음 → confidence / 중간 → happy / 낮음 → defaults
- 독서: 평점 4.5+ → special / 3.5+ → happy / 그 외 → thinking
- 일기: 기분별 매핑 (very_happy → cheering 등)

#### 4단계: AI 결정 로직 (`SmartSherpiManager.getMessage`)

**위치**: `lib/core/ai/smart_sherpi_manager.dart`

## 🎭 성격별 메시지 변형 시스템

### 5가지 성격 타입

#### 1. 활발한 (Energetic)
- **특징**: 느낌표 많음, 에너지 넘침
- **AI 보너스**: +8%
- **예시 메시지**:

  ```
  활발: "와! 오늘도 에너지 넘치게 파이팅!! 💪🔥"
  ```

#### 2. 차분한 (Calm)
- **특징**: 조용하고 사려깊음
- **AI 보너스**: +2%
- **예시 메시지**:
  ```
  일반: "운동 완료!"
  차분: "운동을 완료하셨네요. 몸과 마음이 건강해지고 있어요. 💚"
  ```

#### 3. 유머러스한 (Humorous)
- **특징**: 재치있고 유쾌함
- **AI 보너스**: +5%
- **예시 메시지**:
  ```
  일반: "레벨업 축하해요!"
  유머: "레벨업! 이제 저랑 수평선상에서 만나는 건가요? 😂🎉"
  ```

#### 4. 진지한 (Serious)
- **특징**: 체계적이고 정확함
- **AI 보너스**: -2%
- **예시 메시지**:
  ```
  일반: "퀘스트 완료!"
  진지: "퀘스트가 완료되었습니다. 목표 달성률이 상승했습니다. ✓"
  ```

#### 5. 균형잡힌 (Balanced)
- **특징**: 적절한 균형
- **AI 보너스**: 0%
- **기본 메시지 사용**

## 🚫 중복 방지 메커니즘

### 3단계 중복 방지 시스템

#### 1. 전역 락 (Global Lock)
```dart
if (_isShowingMessage && !forceShow) {
  return; // 이미 메시지 표시 중
}
```
- **목적**: 동시 다발적 호출 방지
- **해제 시점**: 메시지 표시 완료 후

#### 2. 컨텍스트 중복 검사 (3초 룰)
```dart
if (timeDiff.inSeconds < 3 && _lastContext == context) {
  return true; // 3초 내 같은 컨텍스트
}
```
- **목적**: 탭 전환 시 중복 메시지 방지
- **적용**: 같은 컨텍스트 3초 내 무시

#### 3. 메시지 내용 중복 검사 (5초 룰)
```dart
if (dialogue != null && _lastDialogue == dialogue) {
  return true; // 5초 내 같은 내용
}
```
- **목적**: 동일 메시지 반복 방지
- **적용**: 같은 내용 5초 내 무시

### 중복 방지 예외 상황

**`forceShow: true` 사용 케이스**:
- 개인화 설정 변경 알림
- 중요한 시스템 메시지
- 사용자 요청 메시지

## 💡 핵심 포인트 요약

### 메시지가 나타나는 조건

1. **자동 트리거** (70%)
   - 활동 완료 시 (운동, 독서, 일기)
   - 퀘스트 완료 시
   - 레벨업/뱃지 획득 시
   - 모임 참가 시

2. **수동 트리거** (30%)
   - 셰르피 아바타 탭
   - 격려 버튼 클릭
   - 다이얼로그 액션 버튼

### AI vs 정적 메시지 결정 요인

1. **컨텍스트** (가장 중요)
   - Premium: 항상 AI
   - Smart: 80% AI
   - Basic: 40% AI

2. **친밀도 레벨**
   - 높을수록 AI 사용 증가
   - 레벨당 3.3-5% 증가

3. **성격 타입**
   - 활발한: +8%
   - 유머: +5%
   - 차분: +2%
   - 진지: -2%

### 메시지 표시 우선순위

```
1. 중복 검사 (3초/5초 룰)
2. AI 캐시 확인 (즉시)
3. AI 실시간 생성 (2-4초)
4. 정적 메시지 (즉시)
```

### 특별한 케이스

- **운동/독서/일기**: 항상 100% AI 사용
- **일일 목표 전체 달성**: 커스텀 메시지
- **탭 방문 퀘스트**: 메시지 표시 안 함
- **등반**: GlobalClimbingProvider에서 직접 처리
