# 🎮 셰르파 앱 미니게임 시스템 설계서

## 📋 개요

### 시스템 아키텍처
- **진입 비용**: 10 포인트
- **일일 제한**: 최대 5회 도전
- **게임 선택**: 8종 중 랜덤 선택 (가중치 시스템 적용)
- **플레이 시간**: 게임당 30초~2분
- **보상 체계**: 포인트, XP, 아이템, 임시 버프

### 핵심 메커니즘
- 모든 미니게임은 사용자의 5가지 등반 능력치(체력, 민첩, 지구력, 지혜, 집중력)에 영향을 받음
- 난이도는 총 등반력(5가지 능력치 합계)에 따라 자동 조정
- 각 게임은 특정 능력치에 더 큰 가중치를 부여

## 🎯 미니게임 상세 설계

### 1. 🏔️ 눈사태 탈출 (Avalanche Escape)
**장르**: 반사신경 / 회피 게임

#### 게임 컨셉
산 정상에서 갑작스런 눈사태를 만나 긴급히 하산하는 스릴 넘치는 탈출 게임

#### 게임플레이
- **조작법**: 좌우 스와이프로 캐릭터 이동, 상하 스와이프로 점프/슬라이드
- **목표**: 60초간 떨어지는 눈덩이, 바위, 나무 등을 피하며 최대한 많은 거리 하산
- **난이도 증가**: 시간이 지날수록 장애물 속도와 밀도 증가

#### 능력치 영향
- **민첩 (40%)**: 회피 판정 범위 증가
- **집중력 (30%)**: 슬로우모션 게이지 충전 속도
- **체력 (30%)**: 피격 시 받는 데미지 감소

#### 점수 시스템
- 기본 점수: 하산 거리 × 10
- 회피 콤보: 연속 회피 시 ×1.1씩 증가 (최대 ×3.0)
- 아이템 수집: 안전 깃발 +100점, 구급상자 +50점

#### 보상 테이블
| 등급 | 조건 | 포인트 | XP | 특별 보상 |
|------|------|---------|-------|-----------|
| 브론즈 | 300m 이상 | 15-25 | 20 | - |
| 실버 | 500m 이상 | 30-45 | 40 | 10% 확률로 민첩 부스터(1시간) |
| 골드 | 800m 이상 | 50-75 | 80 | 25% 확률로 눈사태 생존자 배지 |

### 2. 🧊 얼음벽 기억력 (Ice Wall Memory)
**장르**: 기억력 / 패턴 인식 게임

#### 게임 컨셉
빙벽 등반 중 안전한 홀드를 기억하고 순서대로 따라가는 기억력 도전

#### 게임플레이
- **조작법**: 화면 탭으로 홀드 선택
- **1단계**: 3초간 안전한 홀드가 빛나며 표시
- **2단계**: 기억한 순서대로 홀드를 탭하여 등반
- **난이도**: 라운드마다 홀드 개수 증가 (3개 → 4개 → 5개...)

#### 능력치 영향
- **지혜 (40%)**: 홀드 표시 시간 증가
- **집중력 (35%)**: 실수 허용 횟수 증가
- **지구력 (25%)**: 제한 시간 증가

#### 점수 시스템
- 기본 점수: 성공한 라운드 수 × 100
- 완벽 보너스: 실수 없이 클리어 시 ×1.5
- 속도 보너스: 빠른 입력 시 추가 점수

#### 보상 테이블
| 등급 | 조건 | 포인트 | XP | 특별 보상 |
|------|------|---------|-------|-----------|
| 브론즈 | 5라운드 | 20-30 | 25 | - |
| 실버 | 8라운드 | 35-50 | 50 | 15% 확률로 집중력 물약 |
| 골드 | 12라운드 | 60-85 | 100 | 30% 확률로 얼음 전문가 칭호 |

### 3. 🪢 로프 관리의 달인 (Rope Management Master)
**장르**: 전략 / 자원 관리 게임

#### 게임 컨셉
제한된 로프를 효율적으로 사용하여 체크포인트를 거쳐 정상에 도달하는 전략 게임

#### 게임플레이
- **조작법**: 드래그로 로프 경로 그리기, 탭으로 앵커 포인트 설정
- **자원**: 총 50m 로프로 100m 절벽 등반
- **전략 요소**: 로프 회수 가능 지점, 바람 영향, 암벽 난이도 고려

#### 능력치 영향
- **지혜 (45%)**: 최적 경로 힌트 제공
- **체력 (30%)**: 로프 내구도 증가
- **지구력 (25%)**: 이동 속도 증가

#### 점수 시스템
- 기본 점수: 도달 높이 × 5
- 효율 보너스: 남은 로프 길이 × 20
- 시간 보너스: (제한시간 - 소요시간) × 10

#### 보상 테이블
| 등급 | 조건 | 포인트 | XP | 특별 보상 |
|------|------|---------|-------|-----------|
| 브론즈 | 50m 도달 | 25-35 | 30 | - |
| 실버 | 75m 도달 | 40-60 | 60 | 20% 확률로 고급 로프 아이템 |
| 골드 | 100m 완등 | 70-100 | 120 | 35% 확률로 로프 마스터 배지 |

### 4. ⏱️ 정상 스프린트 (Summit Sprint)
**장르**: 타이밍 / 리듬 게임

#### 게임 컨셉
움직이는 플랫폼 간 완벽한 타이밍으로 점프하여 정상을 향해 질주

#### 게임플레이
- **조작법**: 탭으로 점프, 홀드로 파워 점프
- **메커니즘**: 타이밍 바가 완벽 구간에 있을 때 점프 시 추가 거리
- **장애물**: 강풍, 낙석, 움직이는 빙판

#### 능력치 영향
- **민첩 (40%)**: 완벽 구간 범위 확대
- **집중력 (35%)**: 타이밍 바 속도 감소
- **체력 (25%)**: 실패 시 재도전 기회

#### 점수 시스템
- 기본 점수: 도달 플랫폼 수 × 50
- 퍼펙트 체인: 연속 완벽 점프 × 보너스 배율
- 무실수 보너스: 한 번도 떨어지지 않고 완주 시 ×2

#### 보상 테이블

### 5. 🗺️ 셰르파의 길 (Sherpa's Path)
**장르**: 경로 찾기 / 퍼즐 게임

#### 게임 컨셉
변화하는 날씨와 지형을 고려하여 최적의 등반 경로를 계획하는 전략 퍼즐

#### 게임플레이
- **조작법**: 드래그로 경로 그리기
- **변수**: 날씨 변화, 체력 소모, 위험 구간, 보급 지점
- **목표**: 최소 체력 소모로 정상 도달

#### 능력치 영향
- **지혜 (50%)**: 날씨 예보 정확도 증가
- **지구력 (30%)**: 체력 소모율 감소
- **집중력 (20%)**: 경로 수정 기회 증가

#### 점수 시스템
- 기본 점수: (100 - 체력 소모량) × 10
- 최단 경로 보너스: 최적 경로 대비 효율성
- 탐험 보너스: 숨겨진 보물 발견 시 +200

#### 보상 테이블

## 💰 통합 보상 시스템

### 포인트 보상 공식
```
최종 포인트 = (기본 점수 × 난이도 계수) + (능력치 보너스) + (연속 플레이 보너스)
```

### XP 보상 공식
```
최종 XP = (기본 XP × 성과 등급) + (첫 클리어 보너스 50)
```

### 특별 보상 풀
- **공통 (60%)**: 포인트 부스터, 임시 버프, 기본 아이템
- **희귀 (30%)**: 영구 능력치 증가 아이템, 특별 칭호
- **전설 (10%)**: 독특한 캐릭터 스킨, 영구 버프, 프리미엄 재화

## 🎯 일일 도전 시스템

### 미니게임 로테이션
- **가중치 시스템**: 최근 플레이하지 않은 게임 확률 증가
- **일일 추천**: 매일 3개 게임 추천 (보상 1.2배)
- **주간 챌린지**: 특정 게임 고득점 도전 (대량 보상)

### 연속 플레이 보너스
- 2연속: 포인트 ×1.1
- 3연속: 포인트 ×1.2
- 4연속: 포인트 ×1.3
- 5연속: 포인트 ×1.5 + 보너스 뽑기권

## ⚖️ 밸런싱 고려사항

### 난이도 스케일링
```dart
// 의사 코드
double difficultyMultiplier = 1.0 + (totalClimbingPower / 1000);
int enemySpeed = baseSpeed * difficultyMultiplier;
int requiredScore = baseScore * difficultyMultiplier;
```

### 능력치 영향력 제한
- 각 능력치의 최대 영향력: 50%
- 최소 보장 성공률: 20% (아무리 능력치가 낮아도)
- 최대 성공률: 80% (아무리 능력치가 높아도)

### 경제 균형
- 일일 최대 획득 포인트: 500 (5회 모두 최고 성과 시)
- 평균 획득 포인트: 200-300
- 투자 대비 수익률: 150-200%

## 🎨 시각적/음향적 요소

### 공통 UI 요소
- **진입 화면**: 8개 게임 룰렛, 스핀 애니메이션
